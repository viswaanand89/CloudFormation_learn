Wait Condition Usage : we can add a wait condition in the template to wait for certain time or the dependent resource sending signal,

For More : https://docs.aws.amazon.com/AWSCloudFormation/latest/UserGuide/using-cfn-waitcondition.html

Example :

  MyWaitCondition:
    Type: AWS::CloudFormation::WaitCondition
    Properties:
      Handle: String
      Timeout: String
      Count: Integer


In the above example after a particular timeout it will proceed to next step,

  MyWaitCondition:
    Type: AWS::CloudFormation::WaitCondition
    DependsOn: MyEC2Instance
    Properties:
      Handle: !Ref MyWaitHandle
      Timeout: '4500'

For Above Example,after that timeout or after EC2 instance resource creation is done
